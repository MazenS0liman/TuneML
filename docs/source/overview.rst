Project Overview
================

TuneML is a Python project for audio processing, classification, and generation with deep learning.
The repository combines:

- Model implementations for transformer and audio tasks
- Notebooks for prototyping and research

Key Source Areas
----------------

- ``tuneml/models``: model architectures
- ``tuneml/trainers``: training loops and trainers
- ``tuneml/data``: dataset-related logic
